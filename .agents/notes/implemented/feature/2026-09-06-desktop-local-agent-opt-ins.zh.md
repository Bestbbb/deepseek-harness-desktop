# Agent Note: 桌面本地代理检查与显式委派选择

Status: implemented

[English](2026-09-06-desktop-local-agent-opt-ins.md) | 中文

## 问题

本地安装 Codex 或 Claude Code，并不能证明 Harness 已安装对应提供方、授予委派工具，或完成该提供方所选 SDK 的认证。桌面入口必须区分这些事实，不能复制凭据或静默向所有会话授予工具。

## 决策

原生扩展窗口将按需执行检查与已保存的提供方启用选择分开。只有指定的内置文档及窗口标识才能调用特权原生命令；远程运行时页面不获得这种访问权限。内置 JSON 目录管理公开元数据及固定启动参数；偏好键必须对应目录条目。检查不接受调用方传入程序或参数，清除继承的机密变量及运行时注入变量，在内部保留有界输出，并只投影已识别的版本和登录事实。现有进程树管理器限制并清理探测进程。检查成功不证明 SDK 查询、额度或推理可用。

构建时的 Node 依赖解析以实际提供方包为锚点定位 Codex 和 Claude 路径，不导入任何 agent。带版本的资源只记录根目录内的 Codex 包装程序和 Claude SDK 平台二进制文件相对路径。原生检查校验该资源，调用内置 Node 加 Codex 包装程序，或直接调用 Claude 二进制程序。元数据无效、文件缺失或符号链接越界时失败，不回退到 PATH。Kimi/Qoder 保留本机 CLI（命令行界面）查找，并排除 PATH 相对路径项。UI 标明执行来源，避免将无关的系统 CLI 版本误认为委派运行时。

桌面部署包含固定版本的上游 Codex、Claude Code 和 ACP（Agent Client Protocol）适配器。隔离桌面主目录中的原子偏好文件选择下次运行时启动要加载的提供方。应用基于内置标准组合生成独立的系统信任 `desktop-local-agents` 预设，只授予所选委派工具。上游可选配置项发生非预期变化时拒绝生成。标准预设及用户编写的预设不会被重写；保存不会中断当前任务。关闭全部选项后，生成的预设根目录仍保留，外部委派工具均停用。

原生选择不提供绕过权限或任意软件包安装。Codex 保留 `never`，Claude Code 保留 `dontAsk`，ACP 使用 `reject`；提供方管理认证、执行和委派输出。实验性 Kimi/Qoder 条目使用本地安装的程序及固定 ACP 参数。缺失程序及 Windows 命令脚本会导致启用被拒绝。ACP 客户端不提供文件系统／终端服务或交互审批桥接；子进程并非文件系统沙箱。[桌面承载决策](../architecture/2026-08-20-tauri-desktop-carrier.zh.md)继续作为运行时隔离、传输与原生生命周期的依据。

精选市场读取内置目录，不依赖网络。搜索及类型筛选作用于已有卡片，保留待保存的选择。「已选择」表示下次启动的草稿，不代表当前运行时状态。诊断不能覆盖草稿，保存失败也不能替换最近确认的选择。每张卡片的详情保留来源及执行限制。

Bundle 市场通过经过认证的 `desktop` 服务打开同一个原生窗口。该无参数命令不携带 agent 标识或账户数据，也不执行检查或启用。浏览器将其标为内置接入，而非可安装的协作组合包。运行时或市场不可用时，原生菜单仍是恢复入口。

## 考虑过的替代方案

**用 PATH CLI 检查代表内置执行就绪。** 否决，因为系统 CLI 可能与提供方固定运行时不同，或在内置运行时可用时缺失。构建时解析也避免在 Rust 中再维护一套 Node 包解析器。

**把 CLI 登录视为集成已启用。** 否决，因为提供方选择独立的固定依赖，而代理预设又独立授予其工具。

**维护市场专用的 agent 启用选择。** 否决，因为两份保存的选择可能在启动时授予不同工具。打开现有原生编辑器可保留唯一偏好管理方，也让耗时检查留在私有同步桥接之外。

**在首个扩展界面安装任意 npm 包。** 否决，因为执行第三方宿主代码需要来源审查、兼容性策略、安装恢复及显式用户信任。精选内置适配器提供范围明确的首条路径。

**在标准预设启用外部委派，或保存时立即重启。** 否决，因为前者未经独立会话选择就改变已有会话行为，后者会中断当前工作。

## 影响

安装包携带选定的上游适配器，不包含 Kimi/Qoder 运行环境发行包。停用的集成不启动代理进程，也不加载提供方插件。独立原生页面不向聊天渲染器增加依赖。移除提供方意味着下次重启时停用，不删除内置文件或提供方自己的账户数据。自定义宿主预设根目录不会合并到生成的桌面预设列表配置；内置及普通用户根目录保持可用。

Rust 测试覆盖目录偏好、缺失程序、启用选择生成、损坏偏好、上游配置项漂移、来源限制、输出大小、超时和机密投影。双语浏览器预期输出覆盖内置文档、先读后写、显式选择及安全错误。打包运行时冒烟测试保留生成的 ACP 提供方和工具授权，将外部命令替换为提供方自己的协议 fixture（测试前置数据）。Codex/Claude 真实产品测试通过本地协议 fixture 调用官方二进制程序；ACP 测试覆盖取消、拒绝和进程清理。真实 Kimi/Qoder 二进制程序、真实账户推理、原生 Windows 交互及公开市场安装仍需单独验收。

打包测试拒绝无效的包装程序元数据、不匹配的 Claude 程序版本和准备根目录以外的路径。原生测试区分内置程序与 PATH 中冲突的 CLI，并在删除内置文件后拒绝回退。目标平台原生打包测试仅使用 `--version` 启动两个真实程序，使用空的私有配置主目录且 PATH 中没有宿主 CLI。该测试不执行登录或消耗提供方额度；桌面工作流在准备目标运行时后执行它。
