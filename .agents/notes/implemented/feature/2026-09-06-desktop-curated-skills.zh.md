# Agent Note: 固定版本的纯数据桌面 Skill 安装

Status: implemented

[English](2026-09-06-desktop-curated-skills.md) | 中文

## 问题

扩展目录本身不能让 Harness 使用远程 Skill（技能）。安装需要可识别的内容、完整资源、用户同意，以及保护用户修改的移除方式，同时不能引入第二套插件执行系统。

## 决策

桌面应用携带精选 manifest（元数据清单），为已审阅的纯文本 Skill 扩展固定 GitHub 提交及 SHA-256。首个条目为 Anthropic 的 Frontend Design Skill，包含许可证及仓库署名说明。只有特权本地扩展窗口可以请求下载、安装或移除；请求指定目录 id 及提交，不接受任意 URL、可执行程序或目标路径。预览使用文本节点，不渲染 HTML 或可执行 Markdown。

下载拒绝重定向，对响应大小和请求时间设限，不携带 Harness 账户凭据。安装在私有临时目录校验完整扩展，再通过不替换现有目标的目录重命名，将其放入桌面主目录。现有文件系统 Skill 提供方负责发现、优先级及指令加载。安装不执行脚本、依赖解析器或准备钩子。安装器记录固定文件列表，并拒绝替换已有目标。移除先校验记录及全部文件，再将扩展移入扫描范围外、唯一分配的恢复目录。

[Agent 启用选择决策](2026-09-06-desktop-local-agent-opt-ins.zh.md)继续管理 SDK/ACP（Agent Client Protocol）启用及下次启动偏好。[Profile 组合包决策](../../archived/simplification/2026-08-09-remove-repository-plugin.md)继续管理可执行第三方插件的安装。文本指令目录不是 Cordis 插件或 profile 补丁；此安装器不重建 repository-plugin 包装层或准备程序。

## 考虑过的替代方案

**下载持续变化的分支或接受任意仓库。** 否决，因为已查看指令可能与安装内容不同，且未声明资源或可执行依赖会绕过精选范围。

**直接写入生效的 Skill 目录。** 否决，因为发现机制可能读到不完整扩展。普通 Unix 重命名同样不足，因为它可能替换已存在的空目录；发布必须拒绝所有已占用目标。

**递归删除已安装目录。** 否决，因为本地修改和无关文件属于用户。校验拒绝被修改的扩展，恢复目录让用户能够找回普通移除操作涉及的文件。

## 影响

目录离线提供并随桌面版本更新；查看和安装需要访问 GitHub。原始 Skill 及许可证保持不变。哈希证明内容身份，而非安全性：已加载指令可能影响工具使用，同一用户的恶意文件系统竞态不在操作系统隔离保证内。移除后现有对话历史保持完整。新会话提供可靠的发现验收路径；UI 状态只报告已校验安装，不代表模型调用。

Rust 测试覆盖完整性拒绝、目标已占用、文件修改或新增、链接根目录、并发不替换发布及可恢复移除。双语浏览器预期输出覆盖查看后同意、安装失败、重试及移除确认。无 Key 的打包 profile 生命周期测试检查安装前不可发现、安装后可加载及移除后消失；显式联网冒烟测试检查真实固定下载及加载。真实模型行为、原生 Windows 执行、任意扩展、远程目录刷新、更新、一键恢复及恢复目录清理不属于本次实现。
