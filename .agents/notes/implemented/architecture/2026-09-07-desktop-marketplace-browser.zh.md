# Agent Note: 桌面插件市场浏览器命令

Status: implemented

[English](2026-09-07-desktop-marketplace-browser.md) | 中文

## 问题

面向非开发者的安装需要可发现的浏览器操作，同时不能暴露原生凭据、文件路径或任意包管理器参数。准备收据不能证明代码正在运行，丢失更改操作的响应也不能证明原生状态未写入。

## 决策

[组合包市场](../../../../packages/desktop/bundle-marketplace/README.zh.md)拥有一个设置标签页和生成的 Remote 网关。桌面覆盖层挂载它；上游 Web Profile 保持独立。网关消费现有 Cordis 准备服务及原生桌面能力，不拥有另一份安装登记。它投影发现元数据和原生选择状态，安装接收目录标识，取消接收准确的待启用 Profile 标识，并省略私有操作错误。

浏览器在安装前要求确认。它在连接代际变化时作废观测，并在命令结束后读取原生状态。它不重放更改操作，也不通过乐观界面推断成功。待启用与试启动代际不表示已安装；活动 Profile 不代表逐插件健康状态。用户完成任务后自行控制完整应用重启。

桌面端将本地目录随运行时打包，并将暂存文件和操作记录保存在独立的 Harness 主目录。原生启动将安装路径编码为 YAML 字面量，从所选 Harness 和 pnpm 的包清单读取版本。资源缺失或包清单无效会拒绝启动。部署限制保留在覆盖层中。随附目录包含可选的 [Focus Timer 组合包](../feature/2026-09-07-focus-timer-bundle.zh.md)；测试组合包保持独立。

已安装观测来自原生选择的 Profile 及上游包解析器，而非准备历史。网关读取包后重新读取原生选择，选择发生变化时拒绝结果。格式错误的 Profile 标记为不可用；包元数据不可读时保留已列出的名称，版本为空。不导入包代码，不推断运行健康状态，也不增加后台清单轮询。“已安装”视图区分已选择、待启用与试启动组合；观测缺失会阻止新安装，但不隐藏目录发现。

安装确认携带观测到的原生 Profile 和已安装版本；null 表示组合包不存在，而非元数据不可读。准备服务检查源清单和副本清单，并在排队前再次检查源版本。版本替换显示两个版本及降级警告；市场不承诺语义版本排序或插件数据兼容性。准备回执记录准备结果，不代表同意替换随后已变化的版本。最终 Profile 比对仍由原生选择负责，这些读取都不是覆盖全部包内容的原子锁。

发现与版本差异搜索使用已读取的目录。版本差异包含更旧及不兼容目标，不会自动升级；未知安装元数据不能证明存在差异。只读历史命令仅在其视图打开或刷新时访问现有有界准备日志，不在每次清单读取中加入历史，也不新建另一份操作数据库。日志失败保持不可用；已验证准备与启用状态分开。连接键控消费方丢弃迟到的历史响应。

[发布检查](../../../../scripts/verify-marketplace-catalog.ts)复用安装器的严格目录与归档校验器，要求双语指南，并在桌面 CI 执行运行时测试前检查每个 tarball 的字节标识。它只读取，不解包或执行插件；成功不代表源码获批。源码提案通过 GitHub 表单与维护者审核，接受的条目通过随附目录分发。[用户指南](../../../../docs/user/guide/marketplace.zh.md)投影到网站的两种语言，不新增远程安装端点。

## 考虑过的替代方案

**使用原生加载页作为长期插件市场。** 不采用，因为正常的发现与命令属于插件组合的产品；产品无法启动时由原生外壳保留恢复能力。

**把命令加入原来的只读清单。** 不采用，因为 Loader 观测与安装意图具有不同所有者。独立标签页保留现有清单，并使可选市场可以移除。

**传输失败后重试安装。** 不采用，因为原生队列可能在确认响应丢失前已提交。调用方重新读取选择状态并保留候选文件。

## 后果

市场仍是可移除插件，使用现有已认证 Web 传输，不改变智能体循环或会话持久化。本地目录、准备和原生启动决策保留各自独立职责。组件测试覆盖确认、断线、重复点击、清单状态及不确定响应；双语浏览器验收使用原生传输夹具，通过真实网关与准备服务执行安装和版本替换。打包验收检查安装、替换、插件拥有的使用入口及卸载；原生启动与恢复验收仍由[启动决策](2026-09-07-desktop-profile-startup-selection.zh.md)拥有。配置与登录、远程更新发现及任务感知重启仍不属于本网关。
