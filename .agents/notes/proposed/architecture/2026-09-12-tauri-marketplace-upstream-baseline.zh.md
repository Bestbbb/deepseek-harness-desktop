# Agent Note: 使用固定上游版本验证 Tauri 插件市场

Status: proposed

[English](2026-09-12-tauri-marketplace-upstream-baseline.md) | 中文

## 问题

上游 `dsh-v0.1.5-rc.2` 在社区 Tauri 应用的同名目录中新增 Electron 应用，并改变已发布的会话数据和客户端组合。无选择的合并可能替换外壳、让桌面构建命令指向错误的包，或使用与已安装应用不同的运行时验证插件。

## 提案

在隔离 worktree 中将核心和 Web 适配到固定标签 `dsh-v0.1.5-rc.2`（`fb2c4b9e698e30edb738bca4cf0618587db7d203`）。保留 [Tauri 载体](../../implemented/architecture/2026-08-20-tauri-desktop-carrier.zh.md)、其部署根目录和[社区自动化策略](../../implemented/process/2026-08-21-community-distribution-automation.zh.md)。[上游同步决策](../../implemented/process/2026-08-21-upstream-rc1-desktop-sync.zh.md) 继续负责依赖生成和版本声明对齐。

本发行版排除 Electron 应用及其构建命令。保留上游私有 Node Host 源码，但不将它加入 Tauri 部署根。验证实际依赖闭包，不以目录名称证明是否包含某项依赖。

先完成上游兼容，再扩展 [Bundle 插件市场](2026-09-06-desktop-plugin-marketplace.zh.md)。桌面和浏览器消费方应共享审核目录及现有 Cordis Bundle 安装模型。本提案不替代载体、安装器或插件市场决策；它们独立的生命周期和信任要求继续有效。

## 考虑过的替代方案

**完整合入官方桌面应用。** 否决，因为这会替换选定的 Tauri 载体，并与现有桌面能力包重名。

**适配过程中追踪每个上游 master 变更。** 否决，因为不断变化的基线会使兼容性证据不明确。另一个已发布标签应通过单独更新评估。

**用 Rust 重写运行时。** 否决，因为这会重复实现 Cordis、提供方和会话行为，而不是通过现有插件维护市场能力。

## 验收标准

- 桌面构建命令指向 Tauri 应用，部署闭包不包含 Electron。
- 原生、运行时和 Bundle 版本与固定 Harness 基线一致。
- 针对性插件市场、社区工作流、客户端、构建、打包运行时和浏览器回放检查通过。
- 隔离会话升级检查保留前代文件字节并验证当前写入器；恢复旧应用不代表支持数据降级。
- 原生 macOS 和 Windows 安装、插件激活、重启恢复及移除在发布前分别验收。

## 风险

桌面注册单元测试显式模拟生成的 Remote 模块。纯源码解析器只接纳这些指定导入，并拒绝未模拟的加载；打包运行时和浏览器测试保留真实生成模块。这种区分避免已有构建掩盖干净检出中的测试失败，同时不以模拟替代运行时验收。

Host API 尚未稳定。单元测试不能单独证明打包后的插件加载、操作系统集成或用户数据迁移安全。生成的远程模块、会话快照、文档目录和安装器依赖必须由各自负责的工具重新生成并审核。现有应用安装和真实用户主目录不用于适配测试。
