# @deepseek-ai/dsh-delegation-launcher

[English](README.md) | 中文

## 概述

从桌面侧栏选择已加载的 agent（智能体）提供方并委派任务。提交前确认目标会话、工作区和账户用量提醒。这个可选组合包使用 Harness 现有的命令与后台任务服务，不安装提供方、不登录账户，也不修改面向模型的工具授权。

## 使用此包

打开“设置 → 插件 → 插件市场”，查看 Delegate Tasks 的安装详情。安装会准备候选组合；结束正在进行的工作后，完整退出并重新打开应用以启用。在“已安装”里选择“委派一个任务”，即可打开此组合包的面板。查看移除详情并确认后，会为下次完整应用启动准备另一组合。目录携带确切的本地产物，不接受任意 npm 包，也不自动配置提供方。

在包含此组合包的运行中 Profile 里，打开会话，从侧栏选择“委派任务”。选择已加载的提供方，输入任务，阅读工作区及访问权限提醒，然后勾选授权框并提交。部分提供方继承父会话上下文。提供方执行和自动父级模型完成处理可能消耗账户额度。命令结果显示在面板内；成功受理并不是 agent 的最终回答。

更换目标会话、连接、提供方或任务都需要重新确认。刷新提供方会按排序后的名称显示，不探测可执行程序、认证状态或模型。未确认的提交不会自动重试：再次提交前先检查现有任务。关闭面板保留草稿，重新加载则不保留。

面板实时显示 subagent 任务状态，空白会话也适用。任务结束后选择“读取结果”，收取有界纯文本输出。“取消任务”需要确认；“正在停止”表示提供方仍在清理。关闭面板清除已显示结果，不取消任务。需要时重新打开并再次读取结果。

Host 在运行命令前验证以下部署限制：

| 配置 | 默认值 | 含义 |
|---|---|---|
| `maxTaskBytes` | `16384` | 去除首尾空白后的任务最大 UTF-8 字节数 |
| `outputLimitBytes` | `32768` | 面板结果及后台任务完成通知的字节限制 |

<a id="understand-the-implementation"></a>
## 了解实现

<details>
<summary>实现细节——点击展开</summary>

[补丁](cordis.patch.yml)挂载 [Host 服务](src/index.ts)。其 Remote 列出已加载提供方，并控制会话所属的 subagent 任务。浏览器通过现有 Commands Remote 提交 `/delegate-task`，即使会话仍处于空白会话视图，也会显示返回的结果。Commands 将输入和结果记录到会话日志。缺失提供方或不可用的任务控制器会在提供方执行前拒绝受理。

后台任务在提供方启动、结果及 dispose（资源释放）全过程保留确切所属 agent。移除此组合包会撤回命令和 UI 贡献，但不会丢弃已受理的任务。现有任务取消和所属方销毁仍负责清理。启动、结果和清理诊断在进入任务通知前替换为通用错误；成功的提供方文本仍是不可信的任务输出。

[浏览器入口](src/client/index.ts)通过 Slots 贡献侧栏和可选市场操作，两者共享一个可见性存储。编辑器按会话和连接约束确认及回执，防止重复提交，并忽略卸载后的延迟更新。它不拥有提供方偏好、凭据或第二套任务调度器。

任务状态使用现有 Session 控制流，不轮询。显式收取结果遵循 Jobs 语义，将任务标记为已报告；不会撤回此前的父级模型唤醒。读取和取消拒绝其他会话、无所属方及非 subagent 任务。结果按完整 UTF-8 字符截断并作为文本渲染；取消回执确认的是请求，不是清理完成。面板不会自动重试未确认的写入。

不发布 invariant 配套入口：Commands 和 Jobs 拥有持久化及生命周期关系，此消费方不保留独立持久化镜像。

</details>

## 模型体验

### 委派任务输入

#### 模型看到什么

所选提供方收到去除首尾空白后的用户任务，形式为一个文本块。提供方拥有子级上下文继承和模型请求组装。此包不添加固定系统提示词或模型工具。

#### Token 影响

任务文本和提供方选择的上下文进入子级请求。安装和列出提供方不产生模型请求。

#### KV Cache 影响

每次委派运行使用提供方的请求上下文。不同任务文本改变该次运行输入；此组合包不改写父级请求前缀。

### 后台任务完成

#### 模型看到什么

现有任务控制器可能向父级传递成功的提供方输出或有界失败通知。此包提供标签 `Delegation: {provider}`，以及通用失败信息 `Delegation failed; check provider configuration.` 或 `Delegation could not complete; check provider configuration.`。控制器拥有通知格式和会话日志记录。

#### Token 影响

未收取的完成通知可能增加父级上下文，并唤醒空闲父级模型。任务输出受 `outputLimitBytes` 限制；显式收取及取消遵循 Jobs 的报告语义。

#### KV Cache 影响

完成处理添加后续上下文，不改写已有前缀。提供方缓存和淘汰不属于此包职责。

## 已知限制与延后工作

<a id="known-limitations-and-deferred-work"></a>

- 打包运行时的浏览器冒烟测试验证离线市场安装、任务调用、结果收取、取消及移除。它使用受控外部提供方和模拟的原生排队回执；原生选择及启动失败恢复有独立 Rust 测试。完整原生窗口验收仍待完成。
- 面板按需读取终态文本，不显示流式输出或非文本结果。共享任务列表可能包含无所属方任务，但此组合包拒绝读取或取消它们。
- 测试使用无账户访问的受控外部提供方。此组合包的真实模型推理、父级完成回放及原生桌面交互仍未验证。
- 任务仅在进程内存在。重新加载面板不会取消任务，但运行时终止后无法恢复。已安装插件是受信任代码，不是沙箱扩展。
